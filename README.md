# Autentico Academy Website

## Project Overview

Autentico Academy is a modern educational institution based in Bangalore, India.

This website serves as the academy's official online presence and is designed to:

- Showcase educational programs
- Present information about the academy
- Generate student enquiries
- Build trust with parents and students
- Promote admissions and internships
- Provide a modern professional online experience

The website should always look premium, clean, trustworthy, and responsive.

---

# Target Audience

Primary visitors include:

- Students (Classes 8–12)
- Parents
- College students
- University students
- Internship applicants
- Professionals looking for certification programs

The website should be easy to navigate for people of all ages.

- Premium

- Professional

- Plenty of white space

- Modern cards

- Apple

- Notion
- Coursera

# Responsiveness

The website must work perfectly on:

- Desktop
- Laptop
- Tablet
- Mobile

No horizontal scrolling.

Maintain good spacing on all screen sizes.

---

# Images

Use high-quality educational images.

Images should represent:

- Students
- Science Labs
- Technology
- Classrooms
- Learning
- Teachers
- Professional Training

Avoid low-quality stock images.

---

# Animations

Animations should be smooth and subtle.

Use Framer Motion where appropriate.

Avoid excessive animations.

---

# Performance

Always optimize:

- Images
- Bundle size
- Loading speed

Prefer lazy loading for large images.

---

# Accessibility

Maintain:

- Good color contrast
- Keyboard accessibility
- Alt text for images
- Semantic HTML

---

# SEO

Every page should include:

- Proper page title
- Meta description
- Open Graph tags
- Twitter Card tags
- Structured headings (H1, H2, H3)

Use descriptive URLs.

---

# Forms

The enquiry form should be easy to complete.

Fields should include validation.

Prevent spam where possible.

---

# Development Rules

Whenever modifying the project:

- Preserve existing design language.
- Never remove working functionality.

- Keep code modular.
- Reuse components whenever possible.
- Keep imports clean.
- Remove unused code.
- Use TypeScript best practices.
- Follow React best practices.
- Keep components readable.
